## Design Specificity Verdict

Authored for a database tool, not category-interchangeable: mono/sans pairing (JetBrainsMono/HankenGrotesk), SQL-flavored copy ("Staged mode — edits are held until you commit", "38 ms" timing, role chips Admin/Developer/Analyst/Read-only), color-coded object types and PK accent. The on-device Board (metric cards re-run live) is a genuine differentiator. Risk: the dark theme reads "generic dev dashboard"; the light theme is competent but loses the identity. Overall coherent and confident.

## Detector + Evidence

`detect.mjs --json lib` returned `[]` (empty JSON — deterministic scan unavailable for Dart UI; no markup to parse). Source measurements instead: contrast pairs text3 (3.5–3.7:1) and text4 (2.1–2.2:1) fail WCAG AA in BOTH palettes (used at 9–12px); SpSwitch 42×25, SpChip ~28px tall, IconBtn boxes 28/30/32/34/38 at many call sites, grid row actions 13px glyphs in a 52px column; FAB `Positioned(right:16, bottom:20)` overlaps the 104px bottom tab bar (browse_tab.dart:236); Insights stats computed client-side from the loaded preview page only (browse_tab.dart `_ColStatCard`), hence "DISTINCT 0 / FILLED 0/0" on a 12-row table.

## Overall Impression

A coherent, thoughtful engineering tool whose riskiest decisions are the ones nobody sees until a thumb meets them: tiny targets, occlusion, and quietly wrong data. Big opportunity: make the on-device interaction layer match the confidence of the component system.

## What's Working

1. Empty states teach: Board ("Run a query, then tap Pin…"), results ("Build a query or run a statement…"), Data tab hint — explicit next steps.
2. Status transparency: timing on results, audit log with SYNTAX/DML/DENIED chips, role badge in both headers, Live/Staged/Masked chips, accent-blue lock shield.
3. Smart defaults: designer pre-fills id + PK + AI; editor ships a runnable sample query; screenshot 30's command palette with tab/ESC hints.

## Priority Issues

- [P1] Touch targets and occlusion: 13px row actions (inspect/delete), IconBtn boxes down to 28px, ~28px chips, 42×25 switch, FAB covering tab-bar hits and grid rows. Why: Casey fat-fingers deletes; Alex can't hit inspect; Diagram/Activity unreachable on table detail. Fix: ≥44px hit areas, move FAB above the bar, labeled row actions. (adapt)
- [P1] Data trust: unordered preview (SELECT * LIMIT n), Insights stats computed from the local page (showed 0/0 on a 12-row table), Search list shows "0 rows" for every table. Why: users trust wrong numbers; wrong-row edits. Fix: ORDER BY PK, server-side stats or mark "from loaded page", populate counts in search. (harden)
- [P1] Keyboard occlusion: command bar, designer, insert sheet — keyboard covers primary actions (18, 23, 30). Why: Commit/Add buttons unreachable; interrupted users quit. Fix: scroll-aware insets, dismiss affordances, primary actions above keyboard fold. (adapt)
- [P2] Results toolbar overflow: "RESULTS" label wraps vertically; 10 ungrouped controls (Export, Pin, 4-mode segmented) on a 360pt row. Fix: two-row toolbar or overflow menu; restack label. (layout)
- [P2] Live destructive actions without confirmation (row delete; drop table only soft-gated by the disabled-by-default toggle) + raw server error codes for novices. Fix: staged-by-default, confirm dialogs, friendlier error summary with code as secondary. (harden, clarify)

## Persona Red Flags

**Casey (mobile, one-hand)**: Insert FAB is thumb-zone — but it covers the tab bar and grid row 24; keyboard opens unprompted in the command bar and buries its actions; 13px row icons are sub-thumb; Arabic keyboard fights LTR fields.

**Alex (power user)**: no real shortcuts on device; one row at a time (no bulk delete/edit); 28px board-card actions slow repeated triage; result view-mode switching requires precise taps on icon-only segments.

**Sam (a11y)**: 9px stat labels, text3/text4 at 2.1–3.7:1 (fail AA), unlabeled icon buttons absent from the a11y tree (uiautomator tree shows no semantics for cog/shield/kebab/magnifier), tap-only interactions, no focus indicators visible.

## Minor Observations

- Type-filter chip row clips "Functions 4" at the screen edge (04/11); source uses horizontal ListView with no scroll cue.
- Tab labels truncate: "Struct…", "Relatio…" (03/05/15).
- Table title wraps "7 cols" onto its own line (15).
- "SQL CONSOLE · ADMIN ROLE" wraps "ROLE" (33).
- Theme resets to light on cold start (observed across restarts).
- Diff sheet with one profile is a dead end (32) — no "create another connection" affordance.
- Chip redundancy: name already says Postgres; engine/local/db chips repeat it (01/02).
- Sun/moon icon inverts meaning by theme (sun shown in dark = "switch to light") — ambiguous at a glance.
- Insight label uses size-9 mono headers (09).
- 15_row_inspector.png: inspector sheet never opened on-device — repeated precise taps on the 13px magnifier produced nothing, while the adjacent trash fired. Unverified-but-indicated interaction failure.
